Suggested flows

Views

Pages the agent made to show results (ask it, for example, “show my YouTube feed as cards”). Views that come from a flow refresh each time you open them.

Memory

The agent saves short facts you tell it or that a task shows (your city, which shops you use…) and uses them in later tasks instead of asking again. Passwords, codes and card or ID numbers are never saved.

Flows

Saved, tested functions your agent runs in one step (for example “read my Gmail results”). The agent writes them when you ask (or after “Automate it”); flows from the online library are used only after you approve them.

Online flow library

Sharing a flow sends only its steps (no page data). You confirm every share. Flows written by others are checked again here and run only on the sites they list.

Apps on this computer (MCP)

Lets Claude Code, Claude Desktop and other MCP apps on this computer search and run your flows in this browser, with your sign-ins (for example “read my Gmail results” inside a Claude Code pipeline). Every run is listed below.
